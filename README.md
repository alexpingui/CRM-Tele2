## 📌 Описание

Разработка клиентской CRM-системы для компании Tele2 с целью автоматизации:
- учёта клиентов,

Система разрабатывалась в рамках курсовой работы по предмету "Базы данных" с целью изучить работу с MS SQL Server

---

## ⚙️ Функционал

- Управление клиентами: добавление, редактирование, фильтрация

---

## 💻 Использованные технологии

- C#
- Windows Presentation Foundation
- MS SQL Server
